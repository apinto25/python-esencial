# Ejercicios

Esta carpeta contiene los ejercicios de práctica del curso **Python esencial**.

## Objetivo

Reforzar, por tu cuenta, los conceptos vistos en cada módulo antes de pasar al siguiente. No todos los módulos tienen ejercicios (por ejemplo, los capítulos introductorios de instalación no los necesitan).

## Estructura

Cada subcarpeta corresponde a un módulo del curso (mismo nombre `cN_...` que en la raíz del repositorio) y contiene uno o varios archivos de ejercicio:

```
ejercicios/
├── c2_conceptos/
├── c3_estructuras_datos/
├── c4_condiciones_ciclos/
├── c5_funciones/
├── c6_modulos_paquetes/
├── c7_paquetes_ambientes/
├── c8_clases/
└── c9_errores_excepciones/
```

Cada archivo `.py` incluye:
- Un **enunciado** en el docstring inicial, con lo que debes lograr.
- Una plantilla con `TODO` donde escribes tu solución.

## Cómo trabajar los ejercicios

1. Abre el archivo del módulo que acabas de ver, por ejemplo:
   ```bash
   python3 ejercicios/c2_conceptos/ejercicio_1_variables.py
   ```
2. Lee el enunciado en el docstring.
3. Completa el código donde dice `TODO`.
4. Ejecuta el archivo para comprobar que tu solución funciona:
   ```bash
   python3 ejercicios/c2_conceptos/ejercicio_1_variables.py
   ```

La idea es que practiques con lo aprendido en el video correspondiente antes de mirar la solución. Si quedas atascado, vuelve a revisar el archivo de ese video en la carpeta del capítulo (por ejemplo [`../c2_conceptos/`](../c2_conceptos/)).

## Soluciones

El archivo [`SOLUCIONES.md`](SOLUCIONES.md) contiene una solución de referencia para cada ejercicio, organizada por carpeta (`c2_conceptos`, `c3_estructuras_datos`, etc.).

Ten en cuenta que:
- Son soluciones de referencia, no la única forma correcta de resolver el ejercicio: si tu código funciona pero se ve distinto, también es válido.
- Intenta resolver el ejercicio por tu cuenta primero, y usa la solución solo para comparar o desatascarte.
